## 遗留缺口 / 发现的问题

1. **`pick_ip` octet 越界回绕**（`orchestrator.rs` 的 `ip_to_u32`）：`10.0.0.300` 被接受并截断为 `10.0.0.44`，而 PHP `ip2long` 对 >255 返回 false。当前测试记录了该行为（`pick_ip_invalid_input_returns_none` 末尾带注释的断言）；修复需改业务代码，超出本任务范围，建议 Phase 2 在 `ip_to_u32` 校验 `p <= 255`。
2. **集成测试依赖外部服务**：`tests/integration.rs` 需本地 MySQL+Redis 才实际执行（无环境变量时跳过），本次 CI 式验证只跑通 mock 路径。
3. **`HttpClient::health` / 实际 HTTP 往返**（ecat-client）未覆盖：需起真实 HTTP server，无现成 test 依赖，留待后续。
4. **gRPC 真实连通**（kvm-server）：`check_auth` 与消息编解码已单测，tonic 信道连接未测（需起真实服务端）。
5. workspace 其余 ~60 个 ecat-* crate 不在本任务范围（任务指定 kvm-server + ecat-lock + ecat-client），如后续要求可继续铺。
