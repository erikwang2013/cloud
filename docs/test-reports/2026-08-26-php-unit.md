## 发现业务代码问题（未修改，按约束记录）

1. **Alert.context 双重编码**：`AlertEngine::trigger()` 传 `json_encode($context)` 字符串给 `Alert::create`，而 Alert 模型 `context` 有 `array` cast，setAttribute 再次 json_encode → 落库为双重编码，读回 `$alert->context` 是 JSON **字符串**而非数组（`app/Monitor/Service/AlertEngine.php` + `app/Monitor/Model/Alert.php:20`）。测试按实际行为断言并注释。建议：AlertEngine 传数组。
2. **Domain register 域名双点**：`DomainService::register()` 用 `$domainName . '.' . $tld` 拼接，而 tld 配置表存带点 `.com` → 生成 `example..com`（`app/Domain/Service/DomainService.php:40`）。测试按实际行为断言并注释。建议：tld 去点后拼接。

| NotificationDispatcher 模板渲染（getLocalizedTitle/body） | 现有 NotificationDispatcherTest 已覆盖基础路径；模板多语言渲染属 I18n 层 |
| Graphql resolver 执行（products 查询真实返回） | resolver 依赖 Product/Resource/Order 模型，Schema 结构已覆盖，执行路径建议走 API 集成测试 |
