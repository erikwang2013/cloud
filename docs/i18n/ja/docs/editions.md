# Cloud Platform — グローバルクラウドリソース取引プラットフォーム

世界中のユーザー向けのクラウドリソース取引プラットフォーム。サーバー（VM）、IP アドレス、クラウドディスク、ドメインなどの製品のオンライン購入と自動交付をサポート。自社運営の物理マシンは Proxmox VE 仮想化で納品し、サードパーティサプライヤーの参入販売もサポート。

## 5. アップグレードパス
```
簡易版 (Lite)
  │
  │  + 決済 + 交付 + ドメイン + チケット + 通知
  │  + 完全な管理画面 + フルセキュリティ + 高並行最適化
  ▼
標準版 (Standard)
  │
  │  + サプライヤーシステム + 外部 API + WebSocket
  │  + Sentry + Feature Flags + Flutter クライアント
  ▼
完全版 (Full)
```

**データ互換:** 簡易版のデータベース構造は標準版のコアテーブルと互換で、直接マイグレーションしてアップグレード可能。標準版から完全版は純粋な増分（サプライヤー関連テーブルの新規追加）で、データマイグレーションは不要。
