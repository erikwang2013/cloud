## Bug real expuesto y corregido

**`HealthRegistry::with_check` llama a `blocking_write()` dentro del runtime de tokio y entra en panic** (`Cannot block the current thread from within a runtime`).
- Disparo: los tests a nivel de ruta encadenan `with_check` en `#[tokio::test]` (antes solo lo llamaban tests síncronos y no se exponía).
- Corrección: pasar a `pub async fn with_check` + `self.checks.write().await` (cambio mínimo, `ecat-health/src/lib.rs:28`).
- Superficie de impacto: ningún llamador en código de producción (grep: solo lo usan los tests dentro del crate); la semántica de la API pasa de síncrona a async; corrección segura.
