## 失败明细
- `POST /api/auth/register(加密)` [auth-flow] status=-1 期望=0 备注: code=-1 msg= 信封内=Server internal error —— User 模型 Encryptable cast 缺 16 字节密钥(aes-128-ecb)，创建用户即 500（应用缺陷）
- `POST /api/auth/register(明文)` [auth-flow] status=500 期望=200 备注: HTTP 500 body=Server internal error —— Encryptable 密钥缺失（应用缺陷）
- `POST /api/auth/login` [auth-flow] status=200 期望=200 备注: code=401 msg=Invalid credentials —— 注册缺陷阻断完整登录链（验证码单次有效，复用报 422）

- service 的 `/admin/api/*` 端点：普通用户 token 应 401/403（AdminRole/RBAC），管理员 token 需 service 侧管理员账号（本环境未配置）
