# Cloud Platform — منصة تداول موارد الحوسبة السحابية العالمية

منصة تداول موارد سحابية موجهة للمستخدمين حول العالم، تدعم الشراء عبر الإنترنت والتسليم التلقائي لمنتجات مثل الخوادم (VM) وعناوين IP والأقراص السحابية وأسماء النطاقات. تُسلَّم الأجهزة المادية الذاتية عبر محاكاة Proxmox VE الافتراضية، مع دعم تسجيل موردين من طرف ثالث للبيع.

## نظرة عامة على الإصدارات
