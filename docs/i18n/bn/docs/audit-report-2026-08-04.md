## ২. আবিষ্কৃত সমস্যা

### CRITICAL (গুরুতর)

#### C1. Docker ডিপ্লয়মেন্টে অ্যাডমিন প্যানেল নেই

**সমস্যা:** Dockerfile শুধু `service/` ডিরেক্টরি কপি করে, docker-compose শুধু 8787 পোর্ট প্রক্সি করে। অ্যাডমিন প্যানেল (port 8788) সম্পূর্ণভাবে Docker-কৃত নয়।

```dockerfile
# docker/Dockerfile — বর্তমানে শুধু service হ্যান্ডেল করে
COPY service/ /app/
```

**প্রভাব:** Docker দিয়ে ডিপ্লয় করা ইউজাররা অ্যাডমিন প্যানেল ব্যবহার করতে পারবেন না। README-এর দাবি করা "Docker Compose এক-ক্লিক স্টার্ট"-এর সাথে মেলে না।

**সুপারিশ:** `admin/`-এর জন্য আলাদা Dockerfile যোগ করুন অথবা মাল্টি-স্টেজ বিল্ড দিয়ে দুটি সার্ভিস একসাথে ডিপ্লয় করুন।

---

#### C2. Docker ডেটাবেস পোর্ট হোস্ট মেশিনে এক্সপোজ

**সমস্যা:** docker-compose.yml-এ MySQL (3306) ও Redis (6379) পোর্ট সরাসরি হোস্ট মেশিনে ম্যাপ করা:

```yaml
mysql:
  ports:
    - "3306:3306"    # পাবলিক নেটওয়ার্কে এক্সপোজ
redis:
  ports:
    - "6379:6379"    # পাবলিক নেটওয়ার্কে এক্সপোজ
```

**প্রভাব:** সার্ভারে পাবলিক IP থাকলে ডেটাবেস বাইরে থেকে অ্যাক্সেসযোগ্য হবে। এটি সিকিউরিটি ইনসিডেন্টের সাধারণ উৎস।

**সুপারিশ:** `ports` ম্যাপিং সরান, অথবা অন্তত `127.0.0.1:3306:3306`-তে বাইন্ড করুন। Docker অভ্যন্তরীণ নেটওয়ার্কেই কমিউনিকেশন সম্ভব।

### HIGH (উচ্চ অগ্রাধিকার)

#### H1. ডুপ্লিকেট SQL ফাইলের কারণে বিভ্রান্তি

**সমস্যা:** প্রজেক্টে ৩টি SQL DDL ফাইল আছে:

| ফাইল | লাইন | টেবিল সংখ্যা | স্ট্যাটাস |
|------|------|------|------|
| `install.sql` (রুট) | 739 | 46 | **বর্তমানে ব্যবহৃত** |
| `admin/install.sql` | 152 | 7 (শুধু wa_*) | পুরনো, ডিলিট হয়নি |
| `docs/database.sql` | 629 | 39 (শুধু erik_*) | পুরনো, ডিলিট হয়নি |

**প্রভাব:** মেইনটেইনাররা ভুল ফাইল এডিট করতে পারেন, ফলে সিঙ্কহীনতা তৈরি হয়।

**সুপারিশ:** `admin/install.sql` ও `docs/database.sql` ডিলিট করুন, অথবা ফাইলের শুরুতে `install.sql`-এর দিকে নির্দেশ করা স্পষ্ট ডিপ্রিকেটেড নোট যোগ করুন।

---

#### H2. ইনস্টলেশন উইজার্ড অডিট ডেটাবেস তৈরি করে না

**সমস্যা:** `install/index.php`-এ `service/.env` তৈরি করার সময় অডিট ডেটাবেস কনফিগ অন্তর্ভুক্ত থাকে:
```ini
AUDIT_DB_DATABASE=cloud_platform_audit
```
কিন্তু ইনস্টলেশন উইজার্ড এই ডেটাবেস কখনো তৈরি করে না। অ্যাপ চালু হলে অডিট লগ লেখার চেষ্টা করলে `Unknown database` এরর হবে।

**প্রভাব:** অডিট লগিং ফিচার অকার্যকর, কমপ্লায়েন্স ক্ষতিগ্রস্ত।

**সুপারিশ:** step 4-এ ইনস্টলেশন এক্সিকিউশনের সময় `CREATE DATABASE IF NOT EXISTS cloud_platform_audit` যোগ করুন।

---

#### H3. Docker-এ Elasticsearch সার্ভিস নেই

**সমস্যা:** docker-compose.yml-এ শুধু app + mysql + redis এই তিনটি সার্ভিস আছে। README টেক স্ট্যাকে Elasticsearch 8.x-কে প্রয়োজনীয় কম্পোনেন্ট হিসেবে স্পষ্টভাবে উল্লেখ করেছে।

**প্রভাব:** ফুল-টেক্সট সার্চ (প্রোডাক্ট, ইউজার, অর্ডার, টিকেট) Docker ডিপ্লয়মেন্টে সম্পূর্ণ অকার্যকর।

**সুপারিশ:** docker-compose.yml-এ Elasticsearch সার্ভিস যোগ করুন।

---

#### H4. Dockerfile-এ PHP এক্সটেনশন নেই

**সমস্যা:** Dockerfile-এ ইনস্টল করা PHP এক্সটেনশন: `gd pdo_mysql zip bcmath redis`। কিন্তু এনভায়রনমেন্ট চেক ৯টি এক্সটেনশন চায়, অনুপস্থিত:
- `intl` (PHP ইন্টারন্যাশনালাইজেশন)
- `xml` (XML পার্সিং)
- `fileinfo` (ফাইল টাইপ ডিটেকশন)

**প্রভাব:** কিছু ফিচার Docker এনভায়রনমেন্টে সাইলেন্টলি ব্যর্থ হতে পারে।

**সুপারিশ:** অনুপস্থিত এক্সটেনশন যোগ করুন: `docker-php-ext-install intl xml fileinfo`

### MEDIUM (মাঝারি অগ্রাধিকার)

#### M1. admin/.env.example-এ কনফিগ আইটেম যথেষ্ট বিস্তারিত নয়

**সমস্যা:** service/.env.example (১৪৬ লাইন) বনাম admin/.env.example (৬৪ লাইন) — পরেরটির কমেন্ট ও কনফিগ আইটেম স্পষ্টভাবে কম।

**সুপারিশ:** admin/.env.example-এ কমেন্ট ব্যাখ্যা যোগ করুন, অন্তত কোন ফিল্ডগুলো service-এর সাথে মিলতে হবে তা চিহ্নিত করুন।

---

#### M2. .env.example-এ HASHIDS_SALT হার্ডকোডেড

**সমস্যা:** দুটি `.env.example` ফাইলেই আছে:
```ini
HASHIDS_SALT=cloud-platform-hashids
```
অপারেটররা যদি সরাসরি `cp .env.example .env` করে এই মান পরিবর্তন না করেন, তাহলে সব ইন্সট্যান্স একই সল্ট শেয়ার করবে।

**সুপারিশ:** `.env.example`-এ প্লেসহোল্ডার ব্যবহার করুন এবং কমেন্টে জোর দিন "অবশ্যই ইউনিক র্যান্ডম ভ্যালু তৈরি করুন"।

---

#### M3. ইনস্টলেশন উইজার্ড সাকসেস পেজ লিংক অকার্যকর

**সমস্যা:** ইনস্টলেশন সম্পন্ন পেজের লিংক `href="#"` ব্যবহার করে, কোনো প্রকৃত ক্লিকযোগ্য URL নেই।

**সুপারিশ:** অন্তত নির্দিষ্ট URL/পোর্ট তথ্য দেখান, সাথে স্টার্ট কমান্ড।

---

#### M4. Docker-এ ইনস্টলেশন উইজার্ড নেই

**সমস্যা:** Dockerfile `install.php` বা `install/` ডিরেক্টরি কপি করে না। Docker ইউজাররা ওয়ান-ক্লিক ইনস্টলেশন উইজার্ড ব্যবহার করতে পারবেন না।

**সুপারিশ:** ডকুমেন্টেশনে স্পষ্টভাবে বলুন Docker ডিপ্লয়মেন্টে ম্যানুয়াল কনফিগ প্রয়োজন, অথবা ইমেজে ইনস্টলেশন উইজার্ড ইন্টিগ্রেট করুন।

---

#### M5. Docker Compose এনভায়রনমেন্ট ভেরিয়েবল অসম্পূর্ণ

**সমস্যা:** docker-compose.yml-এর `environment`-এ একাধিক প্রয়োজনীয় কনফিগ নেই: JWT কী, Hashids সল্ট, এনক্রিপশন কী, SMTP, Stripe ইত্যাদি।

**সুপারিশ:** সম্পূর্ণ এনভায়রনমেন্ট ভেরিয়েবল তালিকা যোগ করুন, অথবা `.env` ফাইল রেফারেন্স করুন।

**সুপারিশ:** স্ট্যান্ডার্ড `.editorconfig` যোগ করুন — PHP-র জন্য ৪ স্পেস ইনডেন্ট, UTF-8, LF নিউলাইন।

## ৯. উপসংহার

প্রজেক্টের সামগ্রিক কোয়ালিটি ভালো, কোর ইনস্টলেশন উইজার্ডের সিকিউরিটি সমস্যা আগের রাউন্ডের অডিটের পর সব ফিক্স হয়েছে। কোড অর্গানাইজেশন পরিষ্কার, মডিউলারাইজেশন ডিগ্রি উচ্চ, ডকুমেন্টেশন সম্পূর্ণ। মূল সমস্যা **Docker ডিপ্লয়মেন্ট কনফিগ অসম্পূর্ণ**-তে কেন্দ্রীভূত — অ্যাডমিন প্যানেল, সার্চ সার্ভিস, PHP এক্সটেনশন অনুপস্থিত, এবং ডেটাবেস পোর্ট এক্সপোজের সিকিউরিটি ঝুঁকি আছে।

**সামগ্রিক মূল্যায়ন: B+** — ফিচার সম্পূর্ণ, সিকিউরিটি কোর ঠিক আছে, Docker ইকোসিস্টেম কনফিগ সম্পূর্ণ করা দরকার।
