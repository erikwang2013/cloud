# Cloud Platform — গ্লোবাল ক্লাউড রিসোর্স ট্রেডিং প্ল্যাটফর্ম

বিশ্বব্যাপী ইউজারদের জন্য ক্লাউড রিসোর্স ট্রেডিং প্ল্যাটফর্ম, সার্ভার (VM), IP ঠিকানা, ক্লাউড ডিস্ক, ডোমেইন ইত্যাদি প্রোডাক্টের অনলাইন কেনা ও অটোমেটিক ডেলিভারি সাপোর্ট করে। নিজস্ব ফিজিক্যাল মেশিন Proxmox VE ভার্চুয়ালাইজেশনের মাধ্যমে ডেলিভারি হয়, সাথে থার্ড-পার্টি সাপ্লায়ারদের প্রবেশ করে বিক্রির সুযোগ দেওয়া হয়।

```
সিমপ্লিফাইড (Lite)
  │
  │  + পেমেন্ট + ডেলিভারি + ডোমেইন + টিকেট + নোটিফিকেশন
  │  + সম্পূর্ণ অ্যাডমিন প্যানেল + ফুল সিকিউরিটি + হাই কনকারেন্সি অপ্টিমাইজেশন
  ▼
স্ট্যান্ডার্ড (Standard)
  │
  │  + সাপ্লায়ার সিস্টেম + এক্সটার্নাল API + WebSocket
  │  + Sentry + Feature Flags + Flutter ক্লায়েন্ট
  ▼
সম্পূর্ণ (Full)
```

**ডেটা কম্প্যাটিবিলিটি:** সিমপ্লিফাইড ভার্সনের ডেটাবেস স্ট্রাকচার স্ট্যান্ডার্ড ভার্সনের কোর টেবিলের সাথে কম্প্যাটিবল, সরাসরি মাইগ্রেট করে আপগ্রেড করা যায়। স্ট্যান্ডার্ড থেকে ফুল আপগ্রেড সম্পূর্ণ ইনক্রিমেন্টাল (নতুন সাপ্লায়ার-সম্পর্কিত টেবিল যোগ), কোনো ডেটা মাইগ্রেশনের প্রয়োজন নেই।
