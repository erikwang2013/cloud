## 暴露并修复的真实 bug

**`HealthRegistry::with_check` 在 tokio 运行时内调用 `blocking_write()` 会 panic**（`Cannot block the current thread from within a runtime`）。
- 触发：路由级测试在 `#[tokio::test]` 中链式调用 `with_check`（此前仅同步测试调用，未暴露）。
- 修复：改为 `pub async fn with_check` + `self.checks.write().await`（最小改动，`ecat-health/src/lib.rs:28`）。
- 影响面：生产代码无调用方（grep 仅 crate 内测试使用），API 语义由同步变 async，属安全修复。
