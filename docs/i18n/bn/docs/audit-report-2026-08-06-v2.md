## ২. ইকোলজিক্যাল কনফিগারেশন যাচাই

### 2.1 env ব্যবহার ও ডেফিনিশন — সম্পূর্ণ ✓

- কোডের সব `getenv()` কী (ডাইনামিক `{PROVIDER}_OAUTH_*` প্যাটার্ন সহ) `.env.example`-এ ডেফিনিশন বা কমেন্ট-আকারে অপশনাল কনফিগ রয়েছে (`#HASHIDS_ALPHABET`, `#POSTER_IMAGE_DRIVER`, `#EXCHANGE_RATE_API_URL`, `#COUNTRY_SEASON_DEFAULT`, `#SECURITY_HSTS_VALUE`)
- টেমপ্লেটে রিডানড্যান্ট আইটেম (নিম্ন ঝুঁকি): `MAIL_FROM_NAME` কোডে কোনো `getenv()` রেফারেন্স নেই, শুধু টেমপ্লেটে রেখে দেওয়া

### 2.2 ডিপেন্ডেন্সি লকিং ✓

- `service/composer.lock` কমিট করা হয়েছে; `.gitignore` আর বাদ দেয় না; `service/.phpunit.cache/` ইগনোর করা হয়েছে

### 2.3 এনভায়রনমেন্ট বিবরণ

- লোকাল মেশিনে পোর্ট 8787 এখনও erp-php দখল করে আছে, cloud-php লোকালি চালু করা যায় না (ডিপ্লয়মেন্ট এনভায়রনমেন্টে কোনো দ্বন্দ্ব নেই)
- `composer validate` vendor প্লাগইন `erikwang2013/security-php`-এর Installer ও composer-এর নিজস্ব eval দ্বন্দ্বের কারণে fatal দেয় (থার্ড-পার্টি প্যাকেজ সমস্যা, এই প্রজেক্টের কোড নয়)

## ৩. সিকিউরিটি প্রোটেকশন যাচাই

### 3.1 গ্লোবাল মিডলওয়্যার চেইন (১১ লেয়ার, সব রাউট কভার করে) ✓

```
Version → CORS → SecurityHeaders → ClientPlatform → GeoBlock
→ WAF (SQLi/XSS) → SecurityPlugin (৩১ ধরনের আক্রমণ সনাক্তকরণ)
→ Locale → Metrics → HashidRequest → Maintenance
```

### 3.2 পাবলিক রাউট রেট লিমিট —— এই রাউন্ডে ১টি ফিক্স

| রাউট | মিডলওয়্যার | রেট লিমিট রুল |
|------|--------|---------|
| register / login / refresh | RateLimit | register 3/min, login 5/min |
| **forgot-password / reset-password** | **RateLimit (এই রাউন্ডে যোগ)** | password_reset 3/5min |
| oauthRedirect / oauthCallback (GET+POST) | RateLimit | oauth 10/60s |
| login/recovery | RateLimit | login 5/min |
| send-sms | RateLimit | sms 5/h |
| captcha/create | RateLimit | captcha 30/60s |

> **ফিক্স**: `forgot-password`/`reset-password` দুটি রাউটে আগের রাউন্ডে `password_reset` রুল ডেফাইন করা হয়েছিল কিন্তু মিডলওয়্যার মাউন্ট করা হয়নি (মেইল বোম্বিং/কোড ব্রুটফোর্স সারফেস), এই রাউন্ডে যোগ করা হয়েছে।

### 3.3 আপলোড ফাইল এক্সপোজার —— এই রাউন্ডে ১টি ফিক্স (উচ্চ ঝুঁকি)

**সমস্যা**: `deployment.md`-এর nginx কনফিগ `location /storage/ { alias .../service/storage/; }` পুরো storage ডিরেক্টরি পাবলিক করে দেয়:

```
storage/
├── backups/    ← ডেটাবেস ব্যাকআপ (.sql.gz) পাবলিক ডাউনলোডযোগ্য
├── apple/      ← AuthKey.p8 প্রাইভেট কী পাবলিক ডাউনলোডযোগ্য (Apple টোকেন ইস্যু করা যাবে)
├── firebase/   ← FCM সার্ভিস অ্যাকাউন্ট ক্রেডেনশিয়াল (প্রাইভেট কী সহ) পাবলিক ডাউনলোডযোগ্য
├── geoip/      ← GeoLite2 ডেটাবেস
└── uploads/    ← আপলোড ফাইল (পাবলিক হওয়া প্রত্যাশিত)
```

**ফিক্স**: deployment.md ও docker/nginx.conf দুটোই `location ^~ /storage/uploads/`-এ পরিবর্তিত হয়েছে, শুধু uploads সাবডিরেক্টরি এক্সপোজ হয়।

### 3.4 অন্যান্য যাচাই ✓

- `verify-email`: ওয়ান-টাইম র্যান্ডম টোকেন (ভেরিফিকেশনের পর খালি করা হয়), ব্রুটফোর্স/এনুমারেশন সারফেস নেই, রেট লিমিট প্রয়োজন নেই
- আপলোড ইন্টারফেস: type হোয়াইটলিস্ট + finfo MIME কনটেন্ট স্নিফিং (আগের রাউন্ডে ফিক্সড); uploads nginx স্ট্যাটিক alias দিয়ে সরাসরি পরিবেশন হয়, PHP এক্সিকিউট হয় না
- JWT: HS256 + Redis ব্ল্যাকলিস্ট (লাইব্রেরিতে jti দিয়ে ভ্যালিডেশন); TOTP লগইন বাধ্যতামূলক + ৫ বার ব্যর্থ হলে ১৫ মিনিট লক
- OAuth: JWKS ভেরিফিকেশন + iss/aud/exp/nonce + email_verified বাধ্যতামূলক (আগের রাউন্ডে ফিক্সড)
- অ্যাডমিন রাউট: AuthMiddleware + AdminRoleMiddleware + ConfirmationMiddleware
