## Bug Real Exposto e Corrigido

**`HealthRegistry::with_check` chamava `blocking_write()` dentro do runtime tokio e causava panic** (`Cannot block the current thread from within a runtime`).
- Disparo: testes no nível de rota chamam `with_check` em cadeia dentro de `#[tokio::test]` (antes, apenas testes síncronos chamavam; não havia sido exposto).
- Correção: alterado para `pub async fn with_check` + `self.checks.write().await` (alteração mínima, `ecat-health/src/lib.rs:28`).
- Impacto: nenhum chamador em código de produção (grep mostra uso apenas nos testes do próprio crate); a API mudou de síncrona para async, correção segura.
