## 2. Новые проблемы, обнаруженные в этом раунде

### 2.1 Синтаксическая ошибка в файле миграции [исправлено]

**Файл:** `service/database/migrations/2026_05_20_000006_create_rbac_permissions.php:41`

**Проблема:** `compact('display_name' => $display)` — недопустимый синтаксис PHP. `compact()` принимает только имена переменных, а не пары «ключ => значение».

```php
// 修复前（语法错误，PHP Parse error）
Capsule::table('roles')->insert(compact('id', 'name', 'display_name' => $display, 'description' => $desc));

// 修复后
Capsule::table('roles')->insert(['id' => $id, 'name' => $name, 'display_name' => $display, 'description' => $desc]);
```

### 2.3 Dockerfile разворачивает только service [не исправлено — архитектурное решение]

**Проблема:** `COPY service/ /app/` в Dockerfile копирует только бэкенд-сервис, без панели управления. Это означает:
- пользователи развёртывания через Docker не могут использовать admin panel
- требуется отдельный Dockerfile для admin или многостадийная сборка

**Статус:** сохранено как известное ограничение. Требуется дополнительное архитектурное решение.
