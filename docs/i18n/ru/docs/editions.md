# Cloud Platform — глобальная торговая платформа облачных ресурсов

Торговая платформа облачных ресурсов для пользователей по всему миру: онлайн-покупка и автоматическая поставка серверов (VM), IP-адресов, облачных дисков, доменов и других продуктов. Собственные физические серверы поставляются через виртуализацию Proxmox VE, также поддерживается размещение и продажа товаров сторонними поставщиками.

## 5. Путь обновления

```
简化版 (Lite)
  │
  │  + 支付 + 交付 + 域名 + 工单 + 通知
  │  + 完整管理后台 + 全套安全 + 高并发优化
  ▼
标准版 (Standard)
  │
  │  + 供应商系统 + 外部 API + WebSocket
  │  + Sentry + Feature Flags + Flutter 客户端
  ▼
完整版 (Full)
```

**Совместимость данных:** структура БД Lite совместима с ключевыми таблицами Standard, возможна прямая миграция с обновлением. Переход Standard → Full — чисто инкрементальный (добавляются таблицы, связанные с поставщиками), миграция данных не требуется.
