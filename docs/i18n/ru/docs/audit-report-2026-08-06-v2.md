### 3.3 Раскрытие загруженных файлов — в этом раунде исправлено 1 место (высокий риск)

**Проблема**: конфигурация nginx в `deployment.md` — `location /storage/ { alias .../service/storage/; }` — делает публичным весь каталог storage:

```
storage/
├── backups/    ← 备份数据库（.sql.gz）公开可下载
├── apple/      ← AuthKey.p8 私钥公开可下载（可签发 Apple 令牌）
├── firebase/   ← FCM 服务账号凭据（含私钥）公开可下载
├── geoip/      ← GeoLite2 数据库
└── uploads/    ← 上传文件（预期公开）
```

**Исправление**: и в deployment.md, и в docker/nginx.conf изменено на `location ^~ /storage/uploads/`, открыт только подкаталог uploads.

### 3.4 Прочие проверки ✓

- `verify-email`: одноразовый случайный токен (обнуляется после проверки), поверхности для перебора/перечисления нет, ограничение частоты не требуется
- Интерфейс загрузки: белый список type + анализ MIME-содержимого через finfo (исправлено в прошлом раунде); uploads отдаётся напрямую через статический alias nginx, PHP не выполняется
- JWT: HS256 + чёрный список Redis (проверка по jti в базе); принудительный TOTP при входе + 5 неудач = блокировка на 15 минут
- OAuth: проверка подписи JWKS + iss/aud/exp/nonce + принудительный email_verified (исправлено в прошлом раунде)
- Административные маршруты: AuthMiddleware + AdminRoleMiddleware + ConfirmationMiddleware
