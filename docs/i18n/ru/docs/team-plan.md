## 2. Остаточные вопросы и риски (проверка 2026-08-17)

### 2.1 Блокирующие развёртывание пункты (высокий приоритет)

- **Пробел окружения DB_PASSWORD**: в service/.env пустая строка → все DB-эндпоинты 500, первопричина 9+1 skip-тестов. Не проблема кода, требуется заполнение значения эксплуатацией (шаблон уже есть в корневом .env.example)
- **Отсутствие каркаса проекта HarmonyOS**: в apps/harmonyos только 3 файла .ets (LoginPage/AuthManager/ApiClient), отсутствуют все конфигурации hvigor/DevEco → сборка невозможна; CI harmonyos-check честно сообщает об ошибке (exit 1)

### 2.2 Расхождения документации и кода (P1, нерешённые 4 пункта)

- Фильтр статуса GET /api/v1/orders не реализован
- Отсутствуют события push WebSocket (заявленные в документации, связанной с websocket_push)
- Область срабатывания ticket.updated неясна
- Мёртвая схема product_attributes (код не использует)

### 2.3 Наблюдаемые пункты средств/безопасности (записи двойной проверки, уровень low)

- **У заказов нет ключа идемпотентности**: повторная отправка одной корзины может создать двойной заказ (medium, рекомендуется запланировать)
- Оценка поставщиков не проверяет принадлежность/статус заказа
- Усечение fee в bcmath (5-й десятичный знак, в сторону недобора <0,0001/операция; с маршрутизацией согласовано, расхождений при сверке нет)
- WAF при большом multipart body всё ещё читает raw (в сценарии json покрыто через $input; multipart — дополнительная поверхность защиты)
- У user_coupons нет уникального ограничения (семантически допускается много заказов/строк у одного пользователя, наблюдение)
- В nginx-admin нет CSP (admin — фронтенд Layui с инлайн-скриптами, сохраняется как есть)

### 2.4 Несогласованность модели прав (P2, новое обнаружение, предстоит консолидация)

- 6 прав только в БД / 19 только в Rbac / различия в назначении ролей (support/supplier)
- AdminRoleMiddleware исключает finance, а Rbac.php определяет роль finance

### 2.5 Прочее

- Новые языковые файлы i18n — англоязычные оригиналы (T6), 7 языков не завершены
- Проверка структуры HarmonyOS CI будет обновлена до реальной сборки hvigor после достройки каркаса
