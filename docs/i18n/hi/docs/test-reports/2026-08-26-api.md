## सीमाएँ विवरण
- Stripe भुगतान बाहरी सेवा है：`POST /api/orders/{id}/pay` केवल त्रुटि-संभाल पथ (4xx/5xx) सत्यापित करता है, वास्तविक भुगतान पूर्ण नहीं कर सकता
- service के `/admin/api/*` एंडपॉइंट：सामान्य उपयोगकर्ता token 401/403 होना चाहिए (AdminRole/RBAC), एडमिन token के लिए service पक्ष का एडमिन खाता चाहिए (इस वातावरण में कॉन्फ़िगर नहीं)
- admin मास्टर कुंजी समस्या (B1) फिक्स होकर दोबारा टेस्ट की गई：8788 सामान्य रूप से शुरू, captcha/dashboard/dict/export/login/CRUD सभी रूट उपलब्ध (कॉपी में पूर्ण रूट फ़ाइल अपडेट हो चुकी है)
- admin पैनल (8788 कॉपी)：सभी रूट उपलब्ध, लॉगिन श्रृंखला (captcha+session+bcrypt) सफलतापूर्वक token लौटाती है；अवलोकन आइटम：user/order/product/config सूची इंटरफ़ेस बिना सेशन कुकी के पहुँच योग्य (HTTP 200, प्रमाणीकरण नहीं)
- पंजीकरण (service दोनों पथ 500)：User मॉडल Encryptable cast में 16 बाइट कुंजी गायब (aes-128-ecb, MissingEncryptionKeyException) → पंजीकरण अनुपलब्ध, उपयोगकर्ता token प्राप्त नहीं हो सकता, token वाले प्रमाणीकरण टेस्ट पूरी तरह स्किप；लॉगिन में कैप्चा एक बार वैध + लॉगिन योग्य उपयोगकर्ता नहीं, केवल 401/422 त्रुटि पथ सत्यापित किया जा सकता है
- सार्वजनिक एंडपॉइंट：इस राउंड में दोबारा टेस्ट किए गए products/{id}、help/{slug}、stripe webhook、domain/* सभी सामान्य हो गए हैं (पहले ModelNotFoundException 500 और domain_tlds कॉलम गायब की समस्या फिक्स हो चुकी है)
- दर सीमा：डिफ़ॉल्ट 60 req/60s प्रति IP, टेस्ट 1s अंतराल से बचकर चलाए गए, छिटपुट 429 अपेक्षित है
- WAF (security-php प्लगइन)：dns_rebinding डिटेक्टर Host=127.0.0.1 को आंतरिक पता मानकर गलती से ब्लॉक करता है (एप्लिकेशन कॉन्फ़िगरेशन समस्या, W1-W3 श्रेणी)；यह सूट `TEST_HOST` पर्यावरण चर के माध्यम से डोमेन Host भेजता है (वास्तविक तैनाती रूप) और इसे बायपास करता है；IP स्वचालित ब्लैकलिस्ट (max_attempts=5) फ़ाइल आधारित है, टेस्ट ट्रैफ़िक के बाद 15 मिनट में स्वतः समाप्त होती है
