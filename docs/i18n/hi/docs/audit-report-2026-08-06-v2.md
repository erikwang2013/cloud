## तीन, सुरक्षा सुरक्षा जाँच

### 3.1 वैश्विक मिडलवेयर श्रृंखला (11 परतें, सभी रूट्स कवर) ✓

```
Version → CORS → SecurityHeaders → ClientPlatform → GeoBlock
→ WAF (SQLi/XSS) → SecurityPlugin (31 प्रकार की अटैक डिटेक्शन)
→ Locale → Metrics → HashidRequest → Maintenance
```

### 3.2 सार्वजनिक रूट रेट लिमिटिंग — इस दौर में 1 स्थान ठीक हुआ

| रूट | मिडलवेयर | रेट लिमिट नियम |
|------|--------|---------|
| register / login / refresh | RateLimit | register 3/min, login 5/min |
| **forgot-password / reset-password** | **RateLimit (इस दौर में पूरक लगाया गया)** | password_reset 3/5min |
| oauthRedirect / oauthCallback (GET+POST) | RateLimit | oauth 10/60s |
| login/recovery | RateLimit | login 5/min |
| send-sms | RateLimit | sms 5/h |
| captcha/create | RateLimit | captcha 30/60s |

> **फिक्स**: `forgot-password`/`reset-password` दो रूट्स पर पिछले दौर में `password_reset` नियम परिभाषित था लेकिन मिडलवेयर माउंट होना छूट गया था (ईमेल बमबारी/कैप्चा ब्रूट-फोर्स सतह), इस दौर में लगाया गया।

### 3.3 अपलोड फ़ाइल एक्सपोज़र — इस दौर में 1 स्थान ठीक हुआ (उच्च जोखिम)

**समस्या**: `deployment.md` के nginx कॉन्फ़िगरेशन में `location /storage/ { alias .../service/storage/; }` पूरे storage निर्देशिका को सार्वजनिक कर देता है:

```
storage/
├── backups/    ← डेटाबेस बैकअप (.sql.gz) सार्वजनिक रूप से डाउनलोड योग्य
├── apple/      ← AuthKey.p8 निजी कुंजी सार्वजनिक रूप से डाउनलोड योग्य (Apple टोकन जारी कर सकती है)
├── firebase/   ← FCM सेवा खाता क्रेडेंशियल (निजी कुंजी सहित) सार्वजनिक रूप से डाउनलोड योग्य
├── geoip/      ← GeoLite2 डेटाबेस
└── uploads/    ← अपलोड फ़ाइलें (अपेक्षित रूप से सार्वजनिक)
```

**फिक्स**: deployment.md और docker/nginx.conf दोनों `location ^~ /storage/uploads/` में बदले गए, केवल uploads उपनिर्देशिका उजागर होती है।

### 3.4 अन्य जाँच ✓

- `verify-email`: एक-बार रैंडम टोकन (सत्यापन के बाद खाली), कोई ब्रूट-फोर्स/एन्यूमरेशन सतह नहीं, रेट लिमिट आवश्यक नहीं
- अपलोड इंटरफ़ेस: type व्हाइटलिस्ट + finfo MIME सामग्री स्निफिंग (पिछले दौर में ठीक हुआ); uploads nginx स्टैटिक alias से सीधे परोसे जाते हैं, PHP निष्पादित नहीं होता
- JWT: HS256 + Redis ब्लैकलिस्ट (डेटाबेस में jti के अनुसार सत्यापन); TOTP लॉगिन अनिवार्य + 5 विफल प्रयासों पर 15 मिनट लॉक
- OAuth: JWKS हस्ताक्षर सत्यापन + iss/aud/exp/nonce + email_verified अनिवार्य (पिछले दौर में ठीक हुआ)
- एडमिन रूट्स: AuthMiddleware + AdminRoleMiddleware + ConfirmationMiddleware
