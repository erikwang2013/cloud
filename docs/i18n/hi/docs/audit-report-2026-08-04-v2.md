### 2.1 माइग्रेशन फ़ाइल सिंटैक्स त्रुटि [ठीक हो गई]

**फ़ाइल:** `service/database/migrations/2026_05_20_000006_create_rbac_permissions.php:41`

**समस्या:** `compact('display_name' => $display)` अमान्य PHP सिंटैक्स है। `compact()` केवल वेरिएबल नाम स्वीकार करता है, कुंजी-मान जोड़े नहीं।

```php
// ठीक करने से पहले (सिंटैक्स त्रुटि, PHP Parse error)
Capsule::table('roles')->insert(compact('id', 'name', 'display_name' => $display, 'description' => $desc));

// ठीक करने के बाद
Capsule::table('roles')->insert(['id' => $id, 'name' => $name, 'display_name' => $display, 'description' => $desc]);
```

**समस्या:** Dockerfile `COPY service/ /app/` केवल बैकएंड सेवा कॉपी करता है, एडमिन पैनल शामिल नहीं। इसका अर्थ:

**स्थिति:** ज्ञात सीमा के रूप में बनाए रखा गया। अतिरिक्त आर्किटेक्चर निर्णय आवश्यक।
