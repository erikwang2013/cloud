# Cloud Platform — वैश्विक क्लाउड संसाधन ट्रेडिंग प्लेटफ़ॉर्म

वैश्विक उपयोगकर्ताओं के लिए क्लाउड संसाधन ट्रेडिंग प्लेटफ़ॉर्म, सर्वर (VM), IP पता, क्लाउड डिस्क, डोमेन जैसे उत्पादों की ऑनलाइन खरीद और स्वचालित डिलीवरी का समर्थन करता है। सेल्फ-ऑपरेटेड फिजिकल मशीन Proxmox VE वर्चुअलाइज़ेशन के माध्यम से डिलीवर होती है, साथ ही तृतीय-पक्ष सप्लायरों के आवेदन और बिक्री का समर्थन करता है।

## पांच, अपग्रेड पथ

```
लाइट संस्करण (Lite)
  │
  │  + पेमेंट + डिलीवरी + डोमेन + टिकट + नोटिफिकेशन
  │  + पूर्ण एडमिन पैनल + पूर्ण सुरक्षा + उच्च समवर्ती अनुकूलन
  ▼
मानक संस्करण (Standard)
  │
  │  + सप्लायर सिस्टम + बाह्य API + WebSocket
  │  + Sentry + Feature Flags + Flutter क्लाइंट
  ▼
पूर्ण संस्करण (Full)
```

**डेटा संगतता:** लाइट संस्करण की डेटाबेस संरचना मानक संस्करण की मुख्य टेबलों के साथ संगत है, सीधे माइग्रेट और अपग्रेड किया जा सकता है। मानक संस्करण से पूर्ण संस्करण में पूर्णतः इंक्रीमेंटल है (सप्लायर संबंधित टेबल जुड़ती हैं), कोई डेटा माइग्रेशन आवश्यक नहीं।
