## दो, पाई गई समस्याएँ

### CRITICAL (गंभीर)

#### C1. Docker डिप्लॉयमेंट में एडमिन पैनल अनुपस्थित

**समस्या:** Dockerfile केवल `service/` निर्देशिका कॉपी करता है, docker-compose केवल 8787 पोर्ट प्रॉक्सी करता है। एडमिन पैनल (admin panel, पोर्ट 8788) का Dockerीकरण बिल्कुल नहीं किया गया।

```dockerfile
# docker/Dockerfile — वर्तमान में केवल service संभालता है
COPY service/ /app/
```

**प्रभाव:** Docker से डिप्लॉय करने वाले उपयोगकर्ता एडमिन पैनल उपयोग नहीं कर सकते। README के «Docker Compose वन-क्लिक स्टार्टअप» के दावे से मेल नहीं खाता।

**सुझाव:** `admin/` के लिए Dockerfile जोड़ें या दोनों सेवाओं को एक साथ डिप्लॉय करने के लिए मल्टी-स्टेज बिल्ड उपयोग करें।

---

#### C2. Docker डेटाबेस पोर्ट होस्ट मशीन पर उजागर

**समस्या:** docker-compose.yml में MySQL (3306) और Redis (6379) पोर्ट सीधे होस्ट मशीन पर मैप किए गए हैं:

```yaml
mysql:
  ports:
    - "3306:3306"    # पब्लिक नेटवर्क पर उजागर
redis:
  ports:
    - "6379:6379"    # पब्लिक नेटवर्क पर उजागर
```

**प्रभाव:** यदि सर्वर के पास पब्लिक IP है, तो डेटाबेस बाहरी रूप से उजागर हो जाएगा। यह सामान्य सुरक्षा दुर्घटनाओं का स्रोत है।

**सुझाव:** `ports` मैपिंग हटाएँ, या कम से कम `127.0.0.1:3306:3306` बाँधें। Docker आंतरिक नेटवर्क पहले से ही संचार कर सकता है।

### HIGH (उच्च प्राथमिकता)

#### H1. डुप्लीकेट SQL फ़ाइलों से भ्रम

**समस्या:** प्रोजेक्ट में 3 SQL DDL फ़ाइलें मौजूद हैं:

| फ़ाइल | पंक्तियाँ | टेबलें | स्थिति |
|------|------|------|------|
| `install.sql` (रूट) | 739 | 46 | **वर्तमान में उपयोग** |
| `admin/install.sql` | 152 | 7 (केवल wa_*) | पुराना, हटाया नहीं गया |
| `docs/database.sql` | 629 | 39 (केवल erik_*) | पुराना, हटाया नहीं गया |

**प्रभाव:** रखरखावकर्ता गलत फ़ाइल संपादित कर सकते हैं, जिससे असमकालिक स्थिति उत्पन्न हो सकती है।

**सुझाव:** `admin/install.sql` और `docs/database.sql` हटाएँ, या फ़ाइल हेडर में `install.sql` की ओर इशारा करने वाली स्पष्ट deprecated घोषणा जोड़ें।

---

#### H2. इंस्टॉलेशन विज़ार्ड ऑडिट डेटाबेस नहीं बनाता

**समस्या:** `install/index.php` `service/.env` जनरेट करते समय ऑडिट डेटाबेस कॉन्फ़िगरेशन शामिल करता है:
```ini
AUDIT_DB_DATABASE=cloud_platform_audit
```
लेकिन इंस्टॉलेशन विज़ार्ड यह डेटाबेस कभी नहीं बनाता। यदि एप्लिकेशन शुरू होने के बाद ऑडिट लॉग लिखने का प्रयास करता है, तो `Unknown database` त्रुटि से विफल होगा।

**प्रभाव:** ऑडिट लॉग फ़ंक्शन अनुपलब्ध, अनुपालन प्रभावित।

**सुझाव:** step 4 इंस्टॉलेशन निष्पादन में `CREATE DATABASE IF NOT EXISTS cloud_platform_audit` जोड़ें।

---

#### H3. Docker में Elasticsearch सेवा अनुपस्थित

**समस्या:** docker-compose.yml में केवल app + mysql + redis तीन सेवाएँ हैं। README तकनीकी स्टैक में Elasticsearch 8.x को आवश्यक घटक के रूप में स्पष्ट रूप से सूचीबद्ध किया गया है।

**प्रभाव:** फुल-टेक्स्ट सर्च (उत्पाद, उपयोगकर्ता, ऑर्डर, टिकट) Docker डिप्लॉयमेंट में पूरी तरह अनुपलब्ध।

**सुझाव:** docker-compose.yml में Elasticsearch सेवा जोड़ें।

---

#### H4. Dockerfile में PHP एक्सटेंशन की कमी

**समस्या:** Dockerfile द्वारा इंस्टॉल किए गए PHP एक्सटेंशन: `gd pdo_mysql zip bcmath redis`। लेकिन पर्यावरण जाँच 9 एक्सटेंशन माँगती है, अनुपस्थित हैं:
- `intl` (PHP अंतर्राष्ट्रीयकरण)
- `xml` (XML पार्सिंग)
- `fileinfo` (फ़ाइल प्रकार पहचान)

**प्रभाव:** कुछ फ़ंक्शन Docker पर्यावरण में मौन रूप से विफल हो सकते हैं।

**सुझाव:** अनुपस्थित एक्सटेंशन जोड़ें: `docker-php-ext-install intl xml fileinfo`

### MEDIUM (मध्यम प्राथमिकता)

#### M1. admin/.env.example कॉन्फ़िगरेशन पर्याप्त विस्तृत नहीं

**समस्या:** service/.env.example (146 पंक्तियाँ) बनाम admin/.env.example (64 पंक्तियाँ), बाद वाले में टिप्पणियाँ और कॉन्फ़िगरेशन आइटम स्पष्ट रूप से कम हैं।

**सुझाव:** admin/.env.example की टिप्पणी स्पष्टीकरण पूरक करें, कम से कम चिह्नित करें कि कौन से फ़ील्ड service पक्ष से मेल खाने चाहिए।

---

#### M2. .env.example में HASHIDS_SALT हार्डकोडेड

**समस्या:** दोनों `.env.example` फ़ाइलों में है:
```ini
HASHIDS_SALT=cloud-platform-hashids
```
यदि ऑपरेटर बिना यह मान बदले सीधे `cp .env.example .env` करता है, तो सभी इंस्टेंस एक ही साल्ट साझा करेंगे।

**सुझाव:** `.env.example` में प्लेसहोल्डर उपयोग करें और टिप्पणी में ज़ोर दें «विशिष्ट रैंडम मान उत्पन्न करना अनिवार्य है»।

---

#### M3. इंस्टॉलेशन विज़ार्ड सफलता पृष्ठ लिंक अमान्य

**समस्या:** इंस्टॉलेशन पूर्णता पृष्ठ का लिंक `href="#"` उपयोग करता है, कोई वास्तविक क्लिक करने योग्य URL नहीं।

**सुझाव:** कम से कम विशिष्ट URL/पोर्ट जानकारी प्रदर्शित करें, स्टार्टअप कमांड के साथ।

---

#### M4. Docker में इंस्टॉलेशन विज़ार्ड शामिल नहीं

**समस्या:** Dockerfile ने `install.php` या `install/` निर्देशिका कॉपी नहीं की। Docker उपयोगकर्ता वन-क्लिक इंस्टॉलेशन विज़ार्ड उपयोग नहीं कर सकते।

**सुझाव:** दस्तावेज़ में स्पष्ट करें कि Docker डिप्लॉयमेंट के लिए मैनुअल कॉन्फ़िगरेशन आवश्यक है, या इमेज में इंस्टॉलेशन विज़ार्ड एकीकृत करें।

---

#### M5. Docker Compose पर्यावरण वेरिएबल अपूर्ण

**समस्या:** docker-compose.yml में `environment` में कई आवश्यक कॉन्फ़िगरेशन अनुपस्थित: JWT कुंजी, Hashids साल्ट, एन्क्रिप्शन कुंजी, SMTP, Stripe आदि।

**सुझाव:** पूर्ण पर्यावरण वेरिएबल सूची पूरक करें, या `.env` फ़ाइल संदर्भित करें।

**समग्र ग्रेड: B+** — फ़ंक्शन पूर्ण, सुरक्षा कोर सही, Docker इकोसिस्टम कॉन्फ़िगरेशन में पूरक आवश्यक।
