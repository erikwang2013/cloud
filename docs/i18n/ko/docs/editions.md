# Cloud Platform — 글로벌 클라우드 리소스 거래 플랫폼

전 세계 사용자를 대상으로 하는 클라우드 리소스 거래 플랫폼으로, 서버(VM), IP 주소, 클라우드 디스크, 도메인 등의 제품을 온라인으로 구매하고 자동으로 인도받을 수 있습니다. 자체 운영 물리 머신은 Proxmox VE 가상화로 인도되며, 제3자 공급업체의 입점 판매도 지원합니다.
